# Centry — план и приёмка Build 0

Build 0 — **личная сборка**, дедлайн 2 недели, ставится через Xcode на телефон автора. Цель — не релиз, а: **автор ведёт свои реальные деньги и не бросает.**

## План работ

| Этап | Содержание                                                                          | Ключевые артефакты                                                 |
| ---- | ----------------------------------------------------------------------------------- | ------------------------------------------------------------------ |
| 1    | Каркас проекта, SQLite, миграции, модели, **денежный модуль + тесты на арифметику** | `src/db/`, `src/models/`, `@utils/money` + `__tests__`             |
| 2    | **Шит ввода** — тот самый, за 4 секунды                                             | `src/views/input/`, `AddTransactionIntent` (TS-часть)              |
| 3    | Главная: герой, чипсы счетов, лента                                                 | `src/views/home/`                                                  |
| 4    | Счета, создание на лету при вводе чужой валюты                                      | `src/views/accounts/`, контроллер счетов                           |
| 5    | История: месяцы, итоги, фильтры, поиск, разбивка, шит деталей                       | `src/views/history/`                                               |
| 6    | Настройки, темы                                                                     | `src/views/settings/`, `usePalette`, resolved-scheme               |
| 7    | **AddTransactionIntent + виджеты S и M + снимок в App Group**                       | `targets/widget/`, `plugins/withWidget.js`, `src/services/widget/` |
| 8    | Siri/Shortcuts, вечернее напоминание                                                | `plugins/withAppIntents.js`, `src/services/notifications/`         |
| 9    | Пустые состояния, полировка, багфикс, установка на телефон                          | —                                                                  |

Порядок ядра ввода внутри этапов 2/7/8: **интент → экран ввода → виджеты → Siri → вечерний пуш** (см. [UX_SPEC](UX_SPEC.md#ядро-ввода)).

## Критерии приёмки Build 0

Сборка готова, когда **все** пункты зелёные:

- [ ] трата записывается за **≤4 секунды и ≤3 тапа**, замерено секундомером;
- [ ] при первом запуске виден **рабочий экран, а не мастер настройки**;
- [ ] ввод суммы в USD на BYN-счёте **предлагает создать USD-счёт одним тапом**;
- [ ] «можно сегодня» **пересчитывается сразу** после записи траты — и в приложении, и в виджете;
- [ ] в деталях записи виден **курс, зафиксированный при её создании**;
- [ ] **обе темы полные**, переключение работает, ни одного нечитаемого элемента;
- [ ] тесты на денежную арифметику **зелёные**, включая границу дня при смене таймзоны;
- [ ] приложение **не делает ни одного сетевого запроса**;
- [ ] скролл истории на **500 записях не проседает**.

## Что НЕ делать в Build 0

Графики/диаграммы · бюджеты по категориям · синхронизация/iCloud · парсинг пушей/OCR · экспорт CSV (только кнопка-заглушка) · повторяющиеся транзакции · теги · редактор категорий · совместный режим · реклама/монетизация · локализация на другие языки (кроме выноса строк в словарь).

Дальнейшие версии — см. [PROJECT_BRIEF §4](PROJECT_BRIEF.md#4-скоуп).
