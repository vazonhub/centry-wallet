## Решения по бутстрапу репозитория (приняты 2026-08-19)

| # | Решение |
| --- | --- |
| B1 | Стек — **Expo managed + prebuild** (как Bsuir Time), а не bare RN. Следствие: `expo-sqlite`, `react-native-mmkv`, WidgetKit через config-плагин + `targets/` |
| B2 | Репозиторий — `vazonhub/centry-wallet`; iOS bundle — `by.vazon.centry`; App Group — `group.by.vazon.centry` |
| B3 | Build 0 — **только iOS**. Android не трогаем (ни `android/`, ни Android-виджет, ни Play-пайплайн) |
| B4 | Полный gitflow (`develop → testing → master`) задокументирован; активна только CI-проверка. EAS-билды и release-workflow лежат готовыми, **включаются на v1.0** (когда будут Apple-аккаунт и EAS-проект) |
| B5 | Архитектура и приёмы наследуются из Bsuir Time; слой `services/api` (axios) заменён на `src/db` (SQLite) |

## Правки и дополнения решений (2026-08-19)

Ответы владельца на `WHAT_I_NEED_FROM_YOU.md`. Часть **разворачивает незыблемые правила** — это осознанное решение автора, зафиксировано явно.
